# Docs

This directory records project decisions and workflows that are too specific
for the public README.

- [Architecture](architecture.md): code layout, data flow, and behavior that
  must stay stable.
- [Workflows](workflows.md): common commands for maintaining and publishing the
  pack.
- [Metadata Format](metadata-format.md): supported `.pw` fields and local
  extensions.
- [Testing](testing.md): verification commands and smoke tests that have been
  run.
