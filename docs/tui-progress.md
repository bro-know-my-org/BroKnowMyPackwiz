每一批改动独立验证和提交；状态只根据已完成证据更新。

当前全套 293 项测试通过，`cargo fmt --check` 和 release 构建通过。
新增 Linux release PTY 烟测覆盖添加页、中文查询、API key 缺失提示及终端恢复。
CurseForge / GitHub 的分页与依赖使用可控响应验证；Linux release PTY 已通过公开 GitHub 仓库的 Release/附件查询、取消及终端恢复。GitHub 真实文件添加两种模式已通过（见文末）；CurseForge 真实鉴权添加和 Windows/macOS 终端尚未实测。
本地 HTTP 故障测试验证：批量下载后项摘要错误时，前项文件及元数据均不发布；全部校验成功时一起提交。

`python3 tests/tui_smoke.py` 使用 release 二进制、临时整合包和隔离用户状态，验证 17 类命令任务的实际 CLI 子进程、持久队列重启确认、中文路径、手动 JAR 保留、模板与导出产物、日志记录和退出后的终端恢复。该脚本目前只支持 Linux；Windows/macOS 的真实终端验收不能据此视为通过。
缺少 `.gitignore`、空元数据集合和未配置模板时，检查/同步/模板准备按原 CLI 规则失败并暂停队列；补齐输入后对应成功路径通过。

新目录进入初始化入口。文件页支持更新预览、直接更新、批量移除确认和来源字段编辑；整合包页支持键鼠菜单与表单。窄窗口操作按钮换行显示。任务页按任务保留最近 2000 条事件，原始 CLI stdout/stderr 单独保存在任务日志目录。
应用错误已增加独立消息键，来源/传输/命令校验的常见错误提供中英文解释；第三方诊断不按英文字符串匹配翻译。

## 剩余验收与已知边界

- 事务已覆盖文件、新建空目录、目录删除、权限变化和文件/目录相互转换；按结构依赖顺序提交与恢复。测试覆盖转换完成后取消、后续写入失败、恢复重开、外部替代文件的备份与明确恢复。release PTY 烟测验证服务端输出中的两种类型转换。
- 写锁现在显式解锁，避免进程创建期间继承的临时句柄延迟释放；重复句柄测试通过。
- 来源、依赖冲突和传输的常见诊断已国际化；部分应用内部诊断仍需补齐。帮助页已包含完整中英文工作流快捷键，并支持键盘与滚轮翻阅；窄窗口测试通过。
- 预览使用暂存文件持有记录：取消、后台结果被丢弃、关闭确认窗口、队列保存失败时清理未提交草稿及已完成的下载；核对指纹后才删除，保留外部改动；入队持久化成功后交给队列管理。相关测试已通过。
- 已补确定性 I/O 故障注入、取消/提交边界和恢复再次崩溃测试；真实磁盘故障、真实 CurseForge 添加和 Windows/macOS 终端未实测。
- 本地环境检查仅发现 `x86_64-unknown-linux-gnu` Rust 目标；没有 MinGW、Wine、cargo-zigbuild 或仓库内 Windows/macOS VM 配置。三平台矩阵仍需远程 CI 执行，不能据本地 Linux 结果宣称全部平台通过。

事务执行采用私有工作目录准备变更，再统一提交文件事务，避免旧核心操作提前修改真实整合包。
准备阶段预检查空间，不使用会共享写入的硬链接；正常终结任务清理完整工作副本，未解决恢复保留备份。
外部编辑器命令按参数解析后直接启动，不通过 shell 执行；变更预览遮罩凭据字段。

队列与恢复状态校验错误使用稳定消息键；新增独立本地化上下文字段，保留原 CLI Display 文本。测试验证新记录往返、旧错误记录读取和双语呈现。已补齐路径、事务固定校验、空间不足、预览过期、命令退出与编辑器结果诊断；路径验证测试确认 CLI 原文与双语界面各自正确。剩余 helper 透传诊断继续核查。

帮助与 README 已提供中英文入口、键鼠操作及队列恢复说明。目录切换、必填字段、TOML 父级结构和依赖版本/side 冲突已改为消息键。此批完整测试仍为 271 项通过；格式与 release 构建通过，Linux 17 类离线任务烟测再次通过。

操作层路径适配覆盖来源、下载、元数据、命令和表单的文件名/相对路径校验。验证与旧 helper 对非法路径及中文合法路径接受行为一致，CLI 错误原文不变，TUI 按消息键翻译；272 项测试、格式检查与 release 构建通过。

配置加载保留 CLI 字符串接口，新增结构化操作接口；来源、队列准备、表单及文件列表接入。布尔值、字符串、整数、路径列表、配置行/读取错误提供消息键与字段位置，TUI 不显示无效字段的原始值。后台列表/平台查询断开也有双语提示。273 项测试、格式检查和 release 构建通过。

扫描与元数据读取新增结构化操作接口，保留 CLI 原诊断；目录/文件读取、符号链接及路径归属错误有双语消息，缺失文件和不可读取忽略文件测试通过。274 项测试、格式检查与 release 构建通过。故障核查确认仍需补齐底层写入故障注入和恢复过程中再次崩溃的直接测试。

新增仅测试构建启用的线程隔离 I/O 故障注入：逐个提交写入边界注入 StorageFull/PermissionDenied，包含最终日志 rename 后、目录 fsync 前；一次失败整批回滚，持续失败保留原始备份供重新恢复。备份复制前后失败不改原文件；恢复替换中途模拟崩溃，重开日志重复恢复成功。取消在最终检查前回滚，标记发布后保持成功。以上是确定性注入，不能据此宣称真实磁盘满载或所有文件系统已验证。279 项测试、格式检查和 release 构建通过。

刷新、哈希读取和索引写入使用结构化操作错误；CLI 接口仍返回原文。测试确认不支持的元数据 side 不改旧索引，哈希缺失文件和写入父目录冲突能双语提示。280 项测试、格式检查与 release 构建通过。

命令入口审计已形成独立验收对照；安装变体可以用现有表单参数复现，并明确 retries/delay 默认值差异。数字表单错误现在说明非负/正整数要求，含溢出与零重试验证；完整测试仍为 280 项，格式检查及 release 构建通过。

剩余平台状态、CF 文件 ID、活动锁元数据和更新文件名冲突已接入消息键。托管目标路径及手动文件碰撞检查提供结构化操作接口，CLI 原文不变；测试验证 side 目录优先、资源包相邻安装和手动文件保留。281 项测试、格式检查与 release 构建通过。

启动失败提示遵循保存的语言偏好；Linux release 烟测验证英文系统/中文偏好及中文系统/英文偏好两种情况，17 类队列任务仍通过。配置错误历史泄露测试先复现无引号 API key 值写入队列 JSON，修复后只持久化消息键与配置位置；重启读取也不含虚构 token，原元数据保持不变。CLI 配置诊断仍按旧文案返回；私有事务草稿备份仍用于恢复。282 项测试、格式检查及 release 构建通过。

键鼠入口补齐：全局语言/帮助/退出、帮助和错误关闭、退出等待/取消回滚/返回、任务重试恢复均可点击；弹窗阻止鼠标穿透，点击明确动作会离开输入焦点。双语最小窗口测试通过；Linux release PTY 实测鼠标打开帮助、关闭帮助及退出，再跑17类队列任务通过。284项测试、格式检查与release构建通过。

表单左右键可双向切换选项，右键不会提交/取消。文件页搜索、类型、排序、详情和重载列表可点击；输入焦点下可点击页签切换。平台控制区按宽度换行，右键按实际点击行选择文件，搜索中的确认不选择旧结果。双语窄窗口测试通过；287 项测试、格式检查与 release 构建通过。

设置页支持滚轮并记录实际可见偏移；双语窄窗口测试确认滚动后点击打开对应设置项。288 项测试、格式检查与 release 构建通过。

错误与退出弹窗支持方向键、翻页键、Home/End 和滚轮，底部保留可见操作。错误弹窗隔离后台页面快捷键与两个搜索框的粘贴输入；中文长文本尾部、缩放限位、内容替换重置和关闭有双语测试。290 项测试、格式检查与 release 构建通过，Linux release PTY 的 17 类离线任务烟测再次通过。

文件详情与 CurseForge 详情增加独立滚动：PgUp/PgDn、Home/End 阅读长内容，详情区域滚轮不改变列表选中项，内容变化后回到顶部；文件窄屏详情及宽屏分栏、长中文简介底部均有双语测试。292 项测试、格式检查与 release 构建通过。 Linux release PTY 的 17 类离线任务烟测再次通过。
