# TUI 实施记录

目标与验收边界见 [tui-plan.md](tui-plan.md)。

| 阶段 | 状态 | 验证 |
| --- | --- | --- |
| 1. 界面与 i18n | 已实现，跨平台验收待阶段 7 | Linux release PTY 启动、搜索、语言切换、退出和终端恢复通过；键鼠/中文/窄窗口单测通过 |
| 2. 操作事件与事务 | 已实现基础与首条元数据路径 | 创建/替换/删除、失败回滚、重复恢复、冲突保留与显式解决测试通过；CLI 共享写锁 |
| 3. 队列与配置 | 已接入，端到端补验中 | 持久队列、重启确认、配置/元数据表单、外部编辑器暂存与确认、最近目录、冲突处理 |
| 4. 来源与更新 | 已接入，综合验收待阶段 7 | CurseForge 搜索/分页/文件/依赖确认；GitHub Release/附件选择；直链、本地文件；更新勾选预览、直接更新及固定候选校验 |
| 5. 下载与同步 | 来源下载已接入，同步待实现 | 可取消的私有传输；元数据和实体文件联合提交；串行下载、重试、摘要校验与托管记录；任务页进度和取消 |
| 6. 模板与导出 | 未开始 | — |
| 7. 三平台验收 | 未开始 | 当前执行环境为 Linux，其他平台尚未实测 |

每一批改动独立验证和提交；状态只根据已完成证据更新。

当前全套 229 项测试通过，`cargo fmt --check` 通过；release 构建按批验证。
新增 Linux release PTY 烟测覆盖添加页、中文查询、API key 缺失提示及终端恢复。
CurseForge / GitHub 的分页与依赖使用可控响应验证；Linux release PTY 已通过公开 GitHub 仓库的 Release/附件查询、取消及终端恢复。真实平台文件添加和 Windows/macOS 终端尚未实测。
本地 HTTP 故障测试验证：批量下载后项摘要错误时，前项文件及元数据均不发布；全部校验成功时一起提交。

事务执行采用私有工作目录准备变更，再统一提交文件事务，避免旧核心操作提前修改真实整合包。
准备阶段预检查空间，不使用会共享写入的硬链接；正常终结任务清理完整工作副本，未解决恢复保留备份。
外部编辑器命令按参数解析后直接启动，不通过 shell 执行；变更预览遮罩凭据字段。
