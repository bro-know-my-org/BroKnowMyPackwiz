# @bro-know-my/packwiz

npm wrapper for the `bkmpw` CLI.

Native packages cover Linux (glibc), Windows and macOS on x64 and ARM64.
npm selects the matching platform package automatically. Linux ARM64 and Windows
ARM64 require a release containing these packages; v0.2.5 does not include them.

```sh
npm install -g @bro-know-my/packwiz
bkmpw --help
```
